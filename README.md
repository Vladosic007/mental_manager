# Ментал — ИИ-психолог для студентов ЮФУ

Веб-приложение психологической поддержки для студентов Южного федерального университета.
В основе — нейросеть **YandexGPT**, дообученная вести себя как тёплый, понимающий помощник,
который знает реалии студенческой жизни: сессия, дедлайны, научрук, общага, выгорание.

> ⚠️ Ментал — это поддержка, а не замена живому психологу. Он не ставит диагнозы.
> При кризисных состояниях он сразу даёт телефон доверия и контакты психологической службы ЮФУ.

## Возможности

- 💬 **Живой чат** с ИИ-психологом «Менталом» на базе YandexGPT (с памятью диалога)
- 🚨 **Детектор кризисных состояний** (ML, Sentence-Transformers) — при опасных сообщениях выдаёт телефоны доверия
- 📚 **База знаний** из 394 психологических концепций (КПТ, гештальт, работа со стрессом) — семантический поиск
- 📊 **Психологические тесты**: уровень стресса и учебное выгорание с разбором результатов
- 😊 **Трекер настроения** с графиком динамики
- 🧠 **Долгосрочная память** — Ментал помнит имя и суть прошлых разговоров

## Технологии

| Слой | Технологии |
|------|-----------|
| Нейросеть | YandexGPT (Yandex Cloud) |
| Бэкенд | Python, FastAPI, uvicorn |
| ML | sentence-transformers, scikit-learn (детектор кризиса, поиск по базе знаний) |
| Фронтенд | HTML, CSS, JavaScript (без фреймворков) |
| Хранилище | JSON-файлы |

## Как запустить

1. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```
2. Создать файл `.env` (по образцу `.env.example`) и вписать свои ключи:
   ```
   YANDEX_API_KEY=...
   YANDEX_FOLDER_ID=...
   ```
3. Запустить сервер:
   - Windows: двойной клик по **`start_webapp.bat`**
   - или вручную: `python webapp/server.py`
4. Открыть в браузере: **http://localhost:8000**

Проверить, что ключ YandexGPT работает: открыть **http://localhost:8000/api/selftest**
(должно быть `"yandex_ok": true`).

## Структура проекта

```
mental_core.py          # «Мозг»: промпт «Ментал», вызов YandexGPT,
                        #   детектор кризиса, поиск по базе знаний, память
webapp/
  server.py             # FastAPI: отдаёт сайт и эндпоинт /api/chat
  static/index.html     # Сайт: лендинг + чат + тесты + трекер настроения
storage.py              # Чтение/запись данных (JSON)
knowledge_base.json     # База психологических знаний (394 концепции)
requirements.txt        # Зависимости
start_webapp.bat        # Запуск одним кликом
legacy/                 # Архив: первая версия в виде Telegram-бота
```
